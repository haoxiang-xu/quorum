# Quorum · agent team 宪章

> **quorum** — 议事有效所需的最少出席者；在分布式系统中，则是达成决议所需的最小节点集。
> 两个含义在此合一：[本文的传唤机制](lifecycle/summons.md)，管的正是"该到的人到齐了没有"。

## 规范来源

Quorum 的唯一规范性宪章来源是 `docs/quorum/` 下的文档集合；本索引的阅读顺序与导航说明不具有规范性，也不新增或复述规则。根目录的 `quorum.md` 仅为兼容入口。
